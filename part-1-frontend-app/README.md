# PART 1: FRONTEND APPLICATION

For this 'take-home' assignment, please create a new, Vue or React application, using the latest version of either framework. Save it to GitHub. We want to be very respectful of your time, so please keep it simple!  The application should only do the following:

* Query a publicly available API. 
* Display the content from that API in a list format. 
* Add one additional feature of your choice to the app (ie, state management, CSS, some client-side effect).  

We will review your app together in a technical interview.
